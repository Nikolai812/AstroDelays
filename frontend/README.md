# Astro Delays React starter

## Apply to an existing Vite project

Copy this archive's `src/` directory over your existing `frontend/src/` directory (keep a backup first), then run from `frontend/`:

```bash
npm install react-router-dom
npm run dev
```

If Vite is not running, start it with `npm run dev`.

## Included

- Shared header, navigation and footer
- Home page and separate MCCF, PYCCF, JAVELIN and ZDCF pages
- Reusable file-upload and parameter-panel components
- Navy/gold theme and responsive layout

The file chooser currently selects files in the browser only. It does not upload them to Python yet. The Calculate button is a placeholder until we define the backend API and each method's parameters.

Place the recolored university logo at `src/assets/logos/univlogo-header_astronomy.svg`.
